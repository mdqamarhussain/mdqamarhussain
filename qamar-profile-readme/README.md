<details>
<summary><b>🔍 Curious how DocSense thinks? (click to open the hood)</b></summary>

<br/>

```mermaid
flowchart LR
    A[📄 Upload PDF] --> B[PyPDF<br/>extract text]
    B --> C[✂️ Chunking]
    C --> D[FastEmbed<br/>embeddings]
    D --> E[(Qdrant<br/>vector store)]
    F[❓ Your question] --> G[🔎 Vector search]
    E --> G
    G --> H[🦙 Ollama LLM]
    H --> I[✅ Answer + page numbers]
```

Because it's FastAPI, you also get free interactive docs at `/docs` (Swagger UI) and `/redoc`, so you can upload a file and start asking questions right from the browser.
